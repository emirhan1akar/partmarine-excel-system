# partmarine-excel-system
This repository contains demo work for the Excel-based analysis and data management systems of the **PartMarine AI SaaS** platform I am developing. The project involves developing example scenarios for digitizing, analyzing, and managing ship spare parts data.

The system can process spare parts data in Excel files, categorize parts, identify duplicate or erroneous records, analyze and report error rates. It also offers basic analysis tools and filtering mechanisms to help improve data accuracy.

This demo is a prototype representing the data processing, analysis, and decision support infrastructure of the AI-powered **PartMarine AI SaaS** platform that will be developed in the future.
